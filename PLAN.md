# PLAN.md — Performance and Risk Attribution Engine on real 13F holdings

This plan expands Section 8 of `instructions/00_kickoff.md` step by step. It adds and removes no step. Precedence (rule 13): a later instruction file beats this plan, which beats the kickoff, which beats the source doc. Methods, conventions, signatures and schemas are in the kickoff (Sections 4 to 7) and in `CLAUDE.md`; this plan cites them rather than restating them.

Items the kickoff leaves unspecified are marked **OPEN-NN** here and listed with 2 options each in `decisions/OPEN.md`. None of them is decided in this plan. A step that depends on an OPEN item does the parts that do not depend on it and reports the rest in the review file (rule 1).

## Every section

- Session N builds every step of Section N and nothing else. One commit per step, `step N.M: <one line>`, on `main`; one push at the end of the section; files staged by explicit path.
- Tests run as `pytest -p socket --disable-socket -q`. No test reads `outputs/` or `data/processed/` (rule 7). No numeric parameter is hard-coded in `attrib/` (rule 6).
- From Section 1 on, the section ends with the fresh-clone check of rule 12: clone the pushed repo into a short temp path, `uv venv`, install from `requirements-lock.txt`, `pip install -e . --no-deps`, run the suite with sockets disabled, paste the full output into the review file. `pip install -e .` needs a build backend, which is D-03. The Python version the lock is resolved for is D-04; the project version is D-05.
- The section ends with `review/section_N.md` (following `review/TEMPLATE.md`) and `instructions/NN_<name>.status.md` (rule 11), committed and pushed.
- How a section's output files are produced before `scripts/run_all.py` exists in Section 8.1 is D-01. The directory of every output table whose path the kickoff does not state is D-02.

## Section 1 — Foundation and EDGAR holdings

**1.1 Config.** Builds `attrib/config.py` and `config.toml`. `config.toml` is Section 7 of the kickoff exactly (written in session 0). `attrib/config.py` implements `Config` (a frozen dataclass with one nested frozen dataclass per config table: `run`, `sample`, `entities`, `edgar`, `openfigi`, `gates`, `linking`, `factors`, `risk`, `bootstrap`, `report`) and `load_config(path: str | Path = "config.toml") -> Config`. Tests in `tests/test_config.py`: `test_keys_match_spec_both_ways` (the set of dotted keys in the loaded file equals the set of keys written in Section 7, checked in both directions, against a literal key list in the test); `test_fund_benchmarks_exist` (every entity with `type = "fund"` names a `benchmark` id that exists as an entity with `type = "benchmark"`); `test_dates_parse_and_are_quarter_ends` (every date string in `[sample]` parses; which of them are checked to be calendar quarter ends is D-30, since `price_start` and `price_end_exclusive` are not). No output files. Review evidence: the test output.

**1.2 EDGAR client.** Builds `EdgarClient` in `attrib/edgar.py`: `__init__(self, user_agent: str, min_interval: float, retries: int, session=None)`, `get_json(self, url) -> dict`, `get_bytes(self, url) -> bytes`. It wraps a `requests.Session` (or the injected `session`), sends `User-Agent: <user_agent>`, keeps at least `edgar.min_interval_s` (0.2 s) between requests, and retries up to `edgar.retries` (3) times on HTTP 429 or 5xx with waits `edgar.backoff_s` ([2, 4, 8] s), then raises. The signature has no parameter for the wait list; how the client gets it is D-06. Tests in `tests/test_edgar_client.py`, all with a fake session and a fake clock (the module's time functions monkeypatched): `test_user_agent_header_sent`, `test_min_interval_respected`, `test_429_then_200_retries_with_configured_waits`, `test_three_failures_raise`. No output files. Review evidence: the test output, including the recorded fake-clock sleep sequence.

**1.3 13F parsing.** Builds in `attrib/edgar.py`: `list_13f_filings(client, cik) -> pd.DataFrame` (FILINGS_13F, from the submissions JSON plus every `filings.files` page; forms 13F-HR and 13F-HR/A), `find_infotable_name(index_json) -> str` (the XML file in the filing index whose name is not `primary_doc.xml`), `parse_13f_infotable(xml: bytes, filing_date: date) -> pd.DataFrame` (HOLDINGS_RAW_13F; lxml, namespace-agnostic on local names; `value_usd = value_raw × 1000` when `filing_date < edgar.units_switch_date`, else `value_raw`), `resolve_13f_books(filings, tables, dates) -> pd.DataFrame` (HOLDINGS; Conventions 4.2 equity rows only, 4.3 CUSIP upper-casing, validation and aggregation, 4.4 amendment rule), and `units_check(book) -> float` (median of `value_usd / shares` over kept rows). Fixtures, committed under `tests/fixtures/13f/akre/` as `{period}_{accession}.xml`: Akre's information table for period 2023-06-30 (accession 0001112520-23-000013, dollars) and Akre's original 13F-HR information table for period 2022-06-30 (thousands; accession identified from the filings list and recorded in the review). Tests in `tests/test_edgar_13f.py`: `test_units_thousands_2022_06_30` and `test_units_dollars_2023_06_30` (units rule on both fixtures); `test_putcall_and_prn_rows_dropped` (synthetic XML); `test_duplicate_cusip_rows_summed` (synthetic); `test_restatement_replaces_book` and `test_new_holdings_appends` (synthetic filings table); `test_median_implied_price_in_range_fixtures` (both fixtures, within [`implied_price_lo`, `implied_price_hi`] = [1, 5000]). No output files. Review evidence: the test output and the median implied price of each fixture printed with `to_string()`.

**1.4 N-PORT parsing.** Builds in `attrib/edgar.py`: `list_nport_filings(client, series_id) -> pd.DataFrame` (FILINGS_NPORT, from the browse-edgar atom feed for type NPORT-P), `parse_nport(xml: bytes) -> tuple[dict, pd.DataFrame]` (header dict with `seriesId` and `repPdDate`; HOLDINGS_RAW_NPORT rows from `invstOrSec`), `resolve_nport_books(filings, raw, dates) -> pd.DataFrame` (HOLDINGS; keeps `assetCat` = EC with `units` = NS; ignores any filing whose period date is not in H; latest filing by filing date wins for a duplicated period; Convention 4.3 aggregation). **1.5 EDGAR pull.** Builds `scripts/pull_data.py --stage edgar`, the only caller of `EdgarClient` (rule 8). It reads `SEC_USER_AGENT` from the environment and stops under rule 4 if it is unset. It resolves the IVV and IWF N-PORT series from `company_tickers_mf.json` (saved as downloaded to `data/raw/sec/company_tickers_mf.json`) and writes `data/raw/sec/series_resolved.csv`; lists filings and writes `data/raw/edgar/13f/filings_{id}.csv` for akre, jensen and polen and `data/raw/edgar/nport/filings_{id}.csv` for ivv and iwf; downloads every 13F information table needed for the periods in H to `data/raw/edgar/13f/{id}/{period}_{accession}.xml`; downloads each NPORT-P `primary_doc.xml` needed, parses it and writes `data/raw/edgar/nport/holdings_{id}.csv` (the XML is not committed); and writes `data/raw/MANIFEST.json` with pull time in UTC, library versions, row counts, sha256 of every committed file under `data/raw/`, and sha256 of every downloaded but uncommitted N-PORT XML. **1.6 Holdings and coverage.** Builds the holdings books for all 5 entities and the date checks, using the parsers from 1.3 and 1.4 (the producing script is D-01). Review evidence: the full coverage table; for the Akre 2023-06-30 book, the 5 largest positions printed both as parsed rows and as the raw XML `infoTable` elements; the fresh-clone check output.

## Section 2 — Mapping, sectors, prices and factors

**2.1 SEC and OpenFIGI pulls.** Extends `scripts/pull_data.py` with `--stage figi` and `--stage sec`. `--stage figi` maps every CUSIP in any book through `https://api.openfigi.com/v3/mapping` with jobs `{"idType":"ID_CUSIP","idValue":cusip,"exchCode":"US"}`, batches of `openfigi.batch_no_key` (10) at `min_interval_no_key_s` (2.4 s), or `batch_with_key` (100) at `min_interval_with_key_s` (0.24 s) when `OPENFIGI_API_KEY` is set, and writes `data/raw/openfigi/mapping.csv` (its columns are D-10). `--stage sec` saves `company_tickers.json` to `data/raw/sec/` as downloaded and, for every CIK reached by ticker → CIK, reads `sic` and `sicDescription` from the submissions JSON into `data/raw/sec/sic.csv` (cik, name, sic, sic_description). The SIC lookup needs the OpenFIGI tickers, so `--stage figi` runs before `--stage sec`. Both update `data/raw/MANIFEST.json`. Test: `tests/test_manifest.py::test_manifest_hashes_match_committed_files` covers the new files. Review evidence: count of CUSIPs mapped and `no_match` per entity, count of CIKs with and without SIC.

**2.2 Mapping module.** Builds `attrib/mapping.py`: `parse_siccodes12(text) -> pd.DataFrame` (industry, sic_lo, sic_hi), `sic_to_ff12(sic, table) -> str` (Other for None or for a SIC in no range), `build_security_map(figi, overrides, tickers, sic, ff12) -> pd.DataFrame` (SECURITY_MAP; first OpenFIGI result with `marketSector` = Equity; `data/manual/overrides.csv` ticker rows applied after OpenFIGI; ticker → CIK by exact match after `-` and `/` are both normalised to `-`; `yf_ticker` = ticker with `/` replaced by `-`; no CIK or no SIC gives Other, logged with reason). The vocabulary of `map_status` is D-12. Tests in `tests/test_mapping.py`: `test_ff12_known_codes` (3571 → BusEq, 2834 → Hlth, 6021 → Money, 1311 → Enrgy, 4911 → Utils, 9999 → Other), `test_ff12_ranges_land_in_one_industry`, `test_ticker_normalisation_brk` (BRK/B → BRK-B), `test_overrides_beat_openfigi`. The FF12 tests read `Siccodes12.txt`, which is pulled in 2.3; how it is available to 2.2 is D-11. No output files. Review evidence: the test output.

**2.3 Prices and French data.** Extends `scripts/pull_data.py` with `--stage prices` (yfinance, `auto_adjust=True`, daily, `start = sample.price_start`, `end = sample.price_end_exclusive`; every `yf_ticker` in SECURITY_MAP to `data/raw/prices/adjclose.parquet`, dates × tickers; AKRIX, JENIX, POLIX, IVV, IWF to `data/raw/prices/nav_adjclose.csv`) and `--stage french` (from `https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/ftp/`: the monthly blocks of `F-F_Research_Data_5_Factors_2x3_CSV.zip` and `F-F_Momentum_Factor_CSV.zip` to `data/raw/french/ff5_monthly.csv` and `data/raw/french/mom_monthly.csv`, and `Siccodes12.zip` to `data/raw/french/Siccodes12.txt`). Tests in `tests/test_data_loaders.py`: `test_french_loader_decimals` (a known month printed in percent from the raw file and in decimals from the loader), `test_price_index_sorted_unique`. Review evidence: the known month in both forms, price panel shape and date range, NAV series first and last dates.

**2.4 Calendar and stock returns.** Builds in `attrib/returns.py` `quarter_calendar(price_index, dates) -> pd.DataFrame` (QUARTERS; q(h) = last date ≤ h in the IVV price index; 30 return quarters from q(2019-03-31) to q(2026-09-30)) plus the daily and monthly stock return functions (daily simple returns; monthly from month-end adjusted closes on calendar periods, never `DateOffset`); those function names are D-13 and the numbering of `t` is D-14.
